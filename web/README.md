# VinaSpends – bản Web

Sổ chi tiêu phong cách vintage 70s, có trợ lý **Mai** đọc thông báo biến động số dư ngay trên máy (không cần mạng, không dùng API ngoài).

- Mở `index.html` bằng trình duyệt, hoặc chạy `npm start` rồi vào http://localhost:3000
- Đồng bộ nhiều thiết bị: Cài đặt → Đồng bộ Firebase → đăng nhập email/mật khẩu (trình duyệt có thêm đăng nhập Google)
- Sao lưu thủ công: Cài đặt → Sao lưu bằng file (xuất/nhập .json)
- Bản Android (tự đọc thông báo ngân hàng): `npm run build:apk`, xem `docs/UX-REDESIGN.md`
